# Pretrained models

Each subdirectory holds one published model with a `model.json` metadata
file recording its full provenance. `*.sjev` binaries are git-ignored
everywhere else; only `models/**/*.sjev` is tracked (see `.gitignore`).

## Model publication rule

Commit ONLY models trained exclusively from public, redistributable or
independently generated data.

DO NOT commit:

- the v3b memory-fine-tuned champion;
- any model trained on `memory.observations`;
- any model trained on private/internal corpora;
- any model whose dataset provenance/licence is uncertain.

Dictionary/thesaurus/Wikispeedia models may be added later only after
their training-data provenance is cleared, with the clearance recorded
in the corresponding `model.json`.

Weights generated by AKADATA tooling from unencumbered data use the
repository's existing BUSL-1.1 licensing unless an underlying dataset
licence requires different treatment; each `model.json` states this
explicitly.
